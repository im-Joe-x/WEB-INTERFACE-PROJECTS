# Full-Featured To-Do App

React + Vite project implementing:
- Full CRUD (create, read, update, delete)
- Filtering: All / Active / Completed
- Persistence via a custom `useLocalStorage` hook
- Drag-to-reorder using the native HTML5 Drag and Drop API
- Dark/light theme via React Context

## Run locally
```
npm install
npm run dev
```
